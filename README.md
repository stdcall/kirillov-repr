# А. А. Кириллов. Элементы теории представлений

Второе издание. Москва, «Наука», 1978.

Текст книги с задачами и указаниями, интерактивными ссылками,
библиографией и алфавитным указателем терминов. Схемы и обложка
выполнены в векторном виде. Пагинация соответствует настоящему набору.

Для сборки нужны Python 3.14, uv, just, Typst 0.15.1,
Typstyle 0.15.1 и Tinymist 0.15.8. Шрифты с лицензиями входят
в репозиторий.

```sh
uv sync --locked
just build
just check
```

PDF находятся в build/. Правила исходников описаны в CONTRIBUTING.md,
границы математических проверок — в checks/README.md.
