# Нормировка центрального элемента в 18.3

Положим E=X₊, F=X₋, H=X₀. Из данных в книге матриц следует
C=σ(R)=−EF+H(2−H)/4. Стандартный элемент Q=4EF+H²−2H равен −4C.
У Диксмье, *Enveloping Algebras* (AMS, 1996), 4.9.22, исключительные
значения Q равны k(k+2), поэтому значения C равны −k(k+2)/4.
Непосредственно на векторе наивысшего веса Eξ=0, Hξ=kξ имеем EFξ=kξ
и Cξ=−k(k+2)ξ/4.

Для общего n≥1 обозначим D=ad F. Соотношения sl₂ дают по индукции
D(Eⁿ)=−nEⁿ⁻¹(H+n−1) и
D²(Eⁿ⁺¹)=−(n+1)[2EⁿF−nEⁿ⁻¹(H+n)(H+n−1)].
Разложим EⁿF как aD²(Eⁿ⁺¹)+bD(Eⁿ)+(αC+β)Eⁿ⁻¹.
Сравнение коэффициентов H²,H,1 и EⁿF даёт

- α=4an(n+1);
- b=a(n+1)(2n+1);
- β=an(n+1)(n²−1);
- −2a(n+1)(2n+1)=1.

Следовательно a=−1/[2(n+1)(2n+1)], b=−1/2,
α=−2n/(2n+1), β=−(n³−n)/(4n+2). В частности β/α=(n²−1)/4.
Это общий расчёт коэффициентов; перебор конечного числа n его не заменяет.

`sl2_casimir_normalization.py` проверяет эти равенства в точной PBW-алгебре
для n=1–8 и скаляр C в представлениях весов 0–12. В компактном базисе он
также устанавливает универсальное тождество σ(R²)=C²+C/3; напечатанный
отрицательный знак сохраняется как опровергнутая проверка. Полная
классификация двусторонних идеалов этим скриптом не доказывается.
